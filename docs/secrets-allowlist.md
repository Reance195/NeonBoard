# 密钥扫描豁免登记（DX-148）

`scripts/check_secrets.py` 在 pre-commit 扫描**本次暂存新增的行**，命中四类模式
（私钥块头 / 云厂 AK 前缀 / 凭据赋值长值 / 长随机串）即拒绝提交。
本文件是唯一的豁免面：只有在这里登记过的「路径 + 行内容哈希」才放行。

## 登记格式（一行一条）

```
<仓库相对路径> <该行内容 sha256 前 12 位> <理由>
```

- 路径：与 `git diff` 输出一致的仓库相对路径（正斜杠），不允许通配与目录级登记。
- 行内容哈希：把该行去掉两端空白后计算，命令：

  ```powershell
  python -c "import hashlib,sys; print(hashlib.sha256(sys.argv[1].encode()).hexdigest()[:12])" "该行完整内容"
  ```

- 理由：为什么这行不是凭据（例如「文档示例密钥」「构建产物摘要，非机密」）。

路径与内容**双匹配**才生效：改一个字符哈希就变，条目随之失效，必须重新登记。
以 `#` 开头的行与不含哈希列的行会被忽略（即本说明本身不构成豁免）。

## 登记纪律

- 登记即留痕：本文件的每次改动都会进 `git log`，理由栏写清楚给后来人看。
- 真凭据一律不得登记兜底——先移除、轮换密钥，再谈其它。
- `--no-verify` 不是豁免通道（宪章 §十一.2-7：豁免面为零）。
