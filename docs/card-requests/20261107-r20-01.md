## 目标
交付官方 QML 插件 `plugins/scheduler/`（id `com.lin.scheduler`，名「定时任务」）：
用户配置时间计划规则（一次性 / 每天 / 每周某时点），到期自动执行看板动作——
建卡、按条件流转、托盘通知。与 plan-hook（git 提交事件驱动）互补，
补齐「时间驱动」自动化入口。纯 QML，零 C++ / CMake 改动，零第三方依赖。

关键设计：
- **槽位幂等**：daily/weekly/once 各自映射到字典序=时间序的槽位键
  （`daily:YYYY-MM-DD` / `weekly:YYYY-MM-DD` / `once:<ms>`），
  触发条件 `dueSlot(now) > state[ruleId].lastSlot`（状态存插件 storage），
  同一槽位至多执行一次。
- **补执行**：退出 / 关机期间错过的槽位只在下次巡检补执行最近一次，
  lastSlot 直接推进，不逐日重放（防重复轰炸）。
- **失败姿势（Z4）**：动作失败 fail-soft——记入执行记录与 pluginHost.log，
  lastSlot 照常推进，不无限重试。

## 验收
见 frontmatter `acceptance`（5 条，分号分隔）。核心是第 3 条——
补执行 + 幂等是调度正确性的主体：预写过期 once 规则 → 启动补执行一次 →
再启动不重复，一条用例同时钉住「错过要补」与「补过不再」两个方向。

## 边界
plugins/scheduler/**;docs/scheduler.md;README.md

- 不做 cron 表达式（daily/weekly/once 三式覆盖看板场景，后续按需扩展）。
- 不做周期续卡（task.completed 驱动的自动再建）——另一痛点，需要时另立卡。
- 不重复实现宿主提醒：ReminderScheduler 已覆盖 due_at 逾期提醒（Z1）。
- 不改宿主任何 C++ / CMake / qml/Main.qml：插件由 deploy.ps1 按目录扫描自动打包，
  官方来源权限自动补授。
