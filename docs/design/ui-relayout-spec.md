# 界面重排设计规格：主界面 + 统一弹窗壳

> 状态：设计稿（2026-11-06）
> 产物：`docs/design/index.html`（主界面原型）、`docs/design/dialogs.html`（弹窗壳原型）、`docs/design/prototype.css`（令牌与壳层）
> 定位：视觉与排版设计。本轮**不改动 QML 代码**，落地需另行领卡实施。

## 0. 结论摘要

| 维度 | 现状 | 重排后 | 变化 |
| --- | --- | --- | --- |
| 顶区竖直占用 | 264 px | 128 px | **省 136 px** |
| 760 px 窗口下看板可用高 | 476 px | 612 px | **+28%** |
| 每列净宽 | 283 px | 296 px | +13 px |
| 弹窗壳数量 | 0（13 套各写各的） | 1 套壳 + 2 种形态 | 统一 |
| 弹窗宽度档 | 7 档（460–780） | 3 档（440 / 560 / 720）+ 抽屉 320 | 统一 |

设计基调：**保留赛博霓虹**（配色、Shader 背景、辉光语言全部不动），重做信息层级与竖直密度。

## 1. 为什么重排

### 1.1 顶区吃掉了看板的 35%

现有布局从标题栏到看板之间有 **264 px**：

| 区块 | 高度 | 所在文件 |
| --- | --- | --- |
| 标题栏 | 40 | `qml/Main.qml` `titleBar` |
| 「工作台」标题 + 副标题 + 统计带 | 40 | `Main.qml:1303` `RowLayout` |
| 项目切换行 | 48 | `Main.qml:1438` `RowLayout` |
| 里程碑行 | 48 | `Main.qml:1485` `RowLayout` |
| 活跃热力横幅 | 80 | `Main.qml:1505` `Rectangle` |

760 px 的默认窗口里，看板只剩 476 px；一列减去列头（36）与快速添加条（32）后，卡片区约 400 px，卡片高 120–160 px —— **一屏只能看 2–3 张卡**。而这是本应用的**主产物**：用户 90% 的时间在看卡片，不在看统计。

### 1.2 信息层级倒挂

- **热力图横幅 72 px 高**，是顶区最大的单一色块，承载的是「过去 13 周完成量」这类回顾性数据，视觉权重却排第二。
- **「逾期 101」藏在右上角小字里**，而它恰恰是唯一需要立刻行动的信号 —— 一个红色数字比一整条热力图更值得被看见。
- 「工作台」标题在侧栏和主区**各出现一次**，侧栏那份占了约 60 px 却零信息量（主区已有）。

### 1.3 筛选器散在两条平行线上

项目切换器一行、里程碑一行、搜索框吊在项目行最右。三套「缩小范围」的控件占了两整行，彼此语义层级不同（项目是外层范围，里程碑是进度阶段，搜索是文本匹配），用户每次筛选要在三处找。

### 1.4 弹窗没有共同的壳

13 个二级界面 + 4 个执行弹窗，各自手写头部、底部、关闭键：

- **宽度 7 档**：460 / 480 / 520 / 560 / 580 / 620 / 660 / 780
- **类型混用**：`TaskComposer` / `SettingsPanel` / `CardDetailPanel` / `ThemeMarketPanel` 是 Qt Quick `Dialog`，其余是自绘 `Rectangle` 浮层
- **行为不一致**：遮罩点击是否关闭、Esc 是否关闭、焦点去哪、按钮在左在右 —— 各写各的
- **最严重的一处**：`PluginPermissionDialog` **点遮罩等同拒绝**（`PluginPermissionDialog.qml:44-52`）。误点一下就是永久拒绝，没有撤销机会。

`Main.qml` 已 4243 行，`SettingsPanel.qml` 1338 行 —— 壳的复制粘贴是体积主因。

## 2. 主界面重排

### 2.1 新竖直预算

| 区块 | 现状 | 新版 | 做法 |
| --- | --- | --- | --- |
| 标题栏 | 40 | 40 | 不动（自绘标题栏是既定设计） |
| 标题 + 统计带 | 40 | 44 | 「工作台 / 专注当下」与统计带同行 |
| 项目切换行 | 48 | — | 并入工具行 |
| 里程碑行 | 48 | — | 并入工具行 |
| 热力图横幅 | 80 | 54 | 压缩 + 可收起为 28 px 摘要条 |
| 工具行（新增） | — | 36 | 项目 / 阶段 / 搜索合并 |
| **合计** | **264** | **128** | **省 136 px** |

### 2.2 工具行：三合一

项目切换器、里程碑 chip、搜索框合并为一行（`Main.qml:1438` 与 `Main.qml:1485` 两个 `RowLayout` 合并为一个）：

```
[● 全局 552][● NeonBoard 112][● 抢号系统 6][● 启动窗改造 7]  [里程碑: 全部 R0 R1 R2 R3 R6 其他]  [⌕ 搜索任务 Ctrl K]
```

- 项目切换器 `maxWidth` 保持自适应（`ProjectSwitcher.qml` 已有），项目再多是滚动不是挤压。
- 里程碑 chip 条保留横向滚动（`StageBar.qml:80` 的 `Flickable` 已有），给整行剩余宽度。
- 搜索框宽度从 300 收到 232，右侧留 `Ctrl K` 提示键 —— 让命令面板的入口可见（现状完全没有提示）。

### 2.3 热力图横幅：可收起

现状 72 px 常驻。重排后：

- 展开态 54 px（热力格 7 px 不变，标题与统计压缩到单行）
- 收起态 28 px 摘要条：`活跃热力 近 13 周 · 共 220 次完成  连续 4 天  [展开]`

热力图是回顾性数据，默认收起不影响主流程；用户想看时点一下就回来。

### 2.4 统计带：保留现状

`TopStatBar.qml` 的单行状态带（R11-01 已做过一轮）不动。它已经是紧凑形态：数字 + 标签、细分隔线分组、零值降饱和、逾期用危险色。

**唯一调整**：顶栏与列头都有计数（顶栏「359 待办」vs 列头「待办 359」）属于信息重复，但两者语义不同 —— 顶栏是全局，列头是本列 —— 且列头计数是看板的天然锚点，移除会破坏扫视节奏。保留两者。

### 2.5 侧栏

- **去掉重复的「工作台 / PERSONAL WORKBENCH」标题块**（`Main.qml:1028-1041`）：主区已有「工作台」标题，侧栏这份占约 60 px 却零信息量。侧栏顶部直接是导航。
- 插件库卡片、插件槽位、底部状态全部保留原位。

### 2.6 横向

侧栏 220 / 留白 20 / 列间距 12 不动，加列按钮 46 → 40，每列净宽 283 → 296 px。

## 3. 统一弹窗壳

### 3.1 壳的构成

```
┌──────────────────────────────────────────┐
│ 标题 18px bold              副标题 11px  ✕ │  头：固定
├──────────────────────────────────────────┤
│                                          │
│              内容区（独立滚动）           │  体：flex:1
│                                          │
├──────────────────────────────────────────┤
│                          取消  │  主操作  │  底：固定
└──────────────────────────────────────────┘
```

三条硬规则：

1. **头固定、体滚动、底固定** —— 现在多个弹窗的头/底会随内容滚走。
2. **底部按钮右对齐**，主操作用 accent 色（`Theme.accent`），次操作用 ghost。
3. **关闭键统一在右上角**（26 × 26，hover 变危险色），Esc 关闭遮罩而非表态。

### 3.2 尺寸档

| 档 | 宽度 | 用途 |
| --- | --- | --- |
| sm | 440 px | 单字段表单：新建任务、权限授权 |
| md | 560 px | 内容型：卡片详情、主题市场、执行相关 |
| lg | 720 px | 工作型：设置、命令面板、插件库、预览中心、执行队列 |
| drawer | 320 px | 右侧抽屉：外观、插件面板、项目全景、列管理 |

全部落在 `Math.min(档位, 窗口宽 - 80)` 的收敛式里，窄屏自动退化。

### 3.3 两种形态

| 形态 | 触发 | 关闭方式 |
| --- | --- | --- |
| 居中弹窗 | 需要用户做决定 | Esc / 点遮罩 / 关闭键 |
| 右侧抽屉 | 浏览型信息（外观 / 全景 / 列管理） | Esc / 点遮罩 / 关闭键 |

现状 `PluginPanel` 锚在右下角、`AppearancePanel` 锚在标题栏下方、`ProjectMapPanel` 锚在右侧，三处位置都不一样 —— 重排统一为右侧抽屉。

### 3.5 权限弹窗的行为修正（唯一的语义变更）

现状 `PluginPermissionDialog.qml:44-52`：遮罩点击 = 拒绝。后果是**误点窗口外的空白就永久拒绝了权限请求**，且没有撤销入口。

重排后：遮罩点击只关闭（等同「稍后再说」），拒绝必须显式点「拒绝」按钮。

这是本次重排里唯一**改变既有行为**的地方。它落在 AGENTS.md Z4「失败模式写码前先定」的口径上：权限请求被误拒属于数据/权限类失败，必须 fail-closed 但要给人事后纠正的路径 —— 显式按钮 + 可重新触发才是正确姿势。

## 5. 不动的部分

明确划界，避免重排蔓延（AGENTS.md Z2「改动最小」）：

- 霓虹 Shader 背景与场景化联动（`shaders/`, `NeonBackground.qml`）
- 6 套主题预设的色值
- 快捷键、无障碍语义（`Accessible.name` / `description` / `selected`）
- 卡片拖拽、撤销栈、落库路径
- 数据模型与数据库 schema
- 插件平台的槽位机制（side / bottom / card）

## 7. 怎么用这份原型

| 文件 | 打开方式 |
| --- | --- |
| `docs/design/index.html` | 双击打开。顶栏可切「新版 / 现状 / 并排对比 / 竖直预算」四个视图，主题按钮切 6 套预设 |

原型是**静态 HTML**，不依赖任何构建产物与网络资源，双击即可打开。
