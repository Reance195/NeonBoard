## 目标
把两件事一次做完：

① **修掉真实缺陷**。当前 `qml/Main.qml` 里筛选态空态 `EmptyState` 的锚定是非法的
（`anchors.centerIn: boardRow`，而 `boardRow` 是空态父级的三层后代），QML 引擎每次启动
都会打一条告警并**忽略这条锚定**，空态面板因此停在窗口左上角 (0,0)，而不是代码注释承诺的
「浮在看板正中间」。修法已用最小复现片段验证：把看板区包一层 `Item`，让 `EmptyState` 与
`boardRow` 成为同一父级下的兄弟，锚定即合法，实测落点精确等于期望居中位置、且零告警。

② **订正核验记录**。`docs/design/ui-relayout-verify.md` 的「遗留问题」一节对该告警的归因
（origin/main 即有、非 R11 引入）是错的，必须改成经溯源与实测得出的准确归因，并补上
「R11-07 引入 / R11-8 未修 / 本卡已修」这段处置链。错的归因比缺陷本身更危险 —— 它会让下一轮
再次以「不是本轮引入」为由跳过同一个问题。

顺带把 R11-12 那条没有兑现的验收项（核验暴露的 scope 内缺陷必须修）在本卡补上，
并在路线图里记一行，收口不留暗账。
